TIMER SOUND FILE

For the timer functionality to work properly, you'll need to add a sound file named 'timer-done.mp3' to this directory.

This sound file will play when the timer reaches zero to alert the user that their activity time is up.

You can use any short, attention-grabbing sound file (a bell, chime, or alert sound works well).

Recommended specifications:
- Format: MP3
- Duration: 1-3 seconds
- Filename: timer-done.mp3
